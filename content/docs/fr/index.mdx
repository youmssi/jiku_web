Jikū remplace le groupe WhatsApp, le fichier Excel et la liste papier : vos invitations, vos billets QR et l'entrée de vos événements d'un côté ; vos rendez-vous et la file du jour de vos services de l'autre. Vos invités et vos clients n'installent rien : tout se passe sur WhatsApp et dans le navigateur.

## Créer votre compte

Sur **Créez votre compte**, donnez votre nom, le **nom de votre organisation**, votre e-mail et un mot de passe : votre espace s'ouvre aussitôt. Un lien de confirmation part à votre adresse ; touchez-le quand vous voulez, avant d'envoyer vos premières invitations. **Renvoyer le lien** le renvoie depuis votre espace.

## Ce que coûte Jikū

Les événements sont gratuits jusqu'à 100 invités par an, l'offre Solo est gratuite pour toujours pour une personne qui reçoit des clients, et la vente de billets coûte 3 % par billet vendu. La [page des tarifs](/pricing) donne le montant exact en francs guinéens, en francs CFA ou en dollars, toutes taxes comprises.

## Protéger votre compte

Dans **Paramètres**, **Sécurité**, le bouton **Activer** de la **Vérification en deux étapes** affiche un QR code. Scannez-le avec une application d'authentification (Google Authenticator, Microsoft Authenticator, 1Password…), puis saisissez le code à 6 chiffres qu'elle affiche. Jikū vous donne alors dix **codes de secours** : copiez-les ou téléchargez-les, ils ne seront plus affichés.

À chaque connexion depuis un nouvel appareil, le code de l'application vous est demandé après le mot de passe. Cochez **Ne plus demander sur cet appareil** sur votre téléphone ou votre ordinateur habituel.

Vous avez perdu votre téléphone ? À l'écran du code, choisissez **Utiliser un code de secours** : chaque code sert une fois. Une fois connecté, créez de **Nouveaux codes de secours** ou désactivez puis réactivez la vérification avec votre nouveau téléphone.

Toujours dans **Sécurité**, **Appareils connectés** liste les navigateurs connectés à votre compte. Un appareil que vous ne reconnaissez pas ? **Déconnecter**, puis changez votre mot de passe. Jikū vous écrit aussi à chaque connexion depuis un nouvel appareil.

## Supprimer votre compte

Dans **Paramètres**, **Compte**, le bouton **Supprimer mon compte** demande votre mot de passe (ou votre compte Google). Si vous êtes le seul propriétaire d'une organisation, cochez la case pour la fermer avec votre compte, ou nommez d'abord un autre propriétaire dans **Membres** pour la garder.

Vous êtes alors déconnecté. Pendant 30 jours, il suffit de vous reconnecter pour tout annuler. Ensuite, votre compte et les données des invités de vos organisations fermées sont effacés ; les factures déjà émises sont conservées, comme la loi l'exige.
