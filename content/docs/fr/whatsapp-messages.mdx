---
title: Écrire un message WhatsApp qui passe
description: Gardez vos messages informatifs pour qu'ils partent vite, au bon prix, sans être bloqués.
---

Meta classe chaque message WhatsApp professionnel. Un message **d'information** (une invitation, un billet, un rappel de rendez-vous) part normalement. Un message jugé **marketing** (une promotion, une remise) coûte plusieurs fois plus cher, est limité par destinataire et peut faire baisser la note de qualité du numéro.

Jikū n'envoie que des messages d'information. Un message qui contient des mots promotionnels est **bloqué avant l'envoi**, pour protéger votre numéro et votre budget.

## Vérifier un message pendant que vous l'écrivez

Sous les zones de texte qui partent sur WhatsApp (le mot d'accueil de l'**Invitation ouverte**, les modèles de message dans **Paramètres**, rubrique **Personnalisation**), Jikū affiche un verdict au fil de la frappe :

- **Message d'information** : il partira comme tel.
- **Risque marketing** : Jikū cite les mots à retirer. Tant qu'ils restent, le message sera bloqué.

C'est exactement la même liste de mots que celle appliquée à l'envoi : ce que vous voyez à l'écran est ce qui se passera.

## Les mots à éviter

Ce sont les mots qui font passer un message pour de la publicité, par exemple :

- en français : « promo », « code promo », « réduction », « solde », « gratuit », « offre spéciale », « cadeau », « bon plan », « achetez maintenant » ;
- en anglais : « discount », « special offer », « free gift », « buy now », « limited offer », « % off ».

## Des exemples

| À éviter | À préférer |
|---|---|
| Promo spéciale : entrée gratuite pour les 50 premiers ! | Vous êtes invité au gala du 12 décembre à 19 h. Confirmez votre venue ici. |
| Achetez maintenant votre place, offre spéciale ce week-end. | Les billets du concert du 20 décembre sont disponibles. Votre place vous attend sur ce lien. |
| Un cadeau vous attend à l'entrée ! | Présentez ce billet à l'entrée, le contrôle se fait en quelques secondes. |

## Quelques réflexes

1. **Dites à quoi sert le message** : une invitation, une confirmation, un rappel, un changement d'horaire.
2. **Parlez de l'événement ou du rendez-vous de la personne**, pas d'une offre.
3. **Gardez un message court**, avec une seule action : répondre, ouvrir le billet, confirmer.
4. **Réservez vos annonces commerciales** à vos propres canaux (statut, réseaux sociaux, groupe).

## Avec votre propre numéro WhatsApp

Si vous envoyez depuis votre propre numéro, Meta vous facture directement vos messages : un message jugé marketing vous coûte donc plus cher. Si votre compte WhatsApp Business n'a plus de moyen de paiement valable, Meta refuse les envois et Jikū l'indique dans le statut du message : ajoutez une carte dans Meta Business Suite, rubrique Facturation, et l'envoi reprend.
